# 运行视频录制指南

考核要求：一段真实运行视频/GIF，展示**正常流程**和**至少一种异常情况**。建议 2—4 分钟，
录屏 1080p 即可，工具用 Win+G（Xbox Game Bar）、OBS 或 PowerPoint 录屏均可。

## 录制前准备

1. `.env` 中已填真实 `DEEPSEEK_API_KEY`，`LLM_MOCK=0`；
2. 启动服务：`python -m uvicorn app.main:app --port 8000`；
3. 浏览器打开 `http://127.0.0.1:8000`，窗口调大一点（图表更清楚）；
4. 建议先自己完整走一遍下面的流程，确认每步的响应符合预期，再正式录。

## 建议分镜（约 3 分钟）

| 段落 | 操作 | 体现的要求 |
| --- | --- | --- |
| 0:00—0:20 | 打开页面，口头/字幕说明项目一句话；指一下右上角"已连接 deepseek-chat"状态 | 真实模型 |
| 0:20—0:50 | 输入「这是我最近四次考试的成绩：78、82、85、88，帮我看看变化趋势」，等结果出来，停 2 秒展示结论、数值卡片和图表 | 场景 1：正常数据 |
| 0:50—1:10 | 追问「继续按这个趋势，第五次可能是多少？」，展示预测值和"预测说明" | 场景 2：连续追问复用数据 |
| 1:10—1:40 | 问「如何提高复习效率？」，展开"资料出处"，指一下命中片段与来源 | 场景 4：真实检索 |
| 1:40—2:00 | 问「量子纠缠的物理机制是什么？」，展示"资料不足"的回答 | 场景 5：不编造引用 |
| 2:00—2:25 | 输入「我这次考了八十五分，帮我分析一下变化趋势」，展示工具拒绝 + 明确原因；再补一次正确数据（如「加上第二次 82 分、第三次 85 分，再看趋势」）说明用户可修改后继续 | 场景 3：异常情况 |
| 2:25—2:50 | 点右侧"分析记录"任一条展示历史详情；点"新会话" | 任务 5：历史记录 |
| 2:50—3:00 | （可选）终端里展示 `python scripts/verify_calc.py` 全部 PASS 的输出 | 验证证据 |

## 录完后

- 导出为 MP4 或 GIF，放到仓库外的网盘/附件，或压缩后放 `docs/`（已在 `.gitignore` 排除大文件，按需调整）；
- 在 README 或提交邮件里附上链接；
- 如果单文件超过邮箱/仓库限制，可以只截取"正常流程 + 异常"两段。
