# 检索资料及获取说明

本目录是检索工具（`search_study_knowledge`）的本地知识库，共 4 篇 Markdown 资料：

| 文件 | 主题 | 来源 |
| --- | --- | --- |
| 学习效率与成绩提升.md | 主动回忆、间隔重复、错题本、时间管理 | 依据公开的学习科学常识整理（间隔重复/主动回忆为认知心理学领域的成熟结论，可参考《认知天性》等书），由本人用自己的话重写 |
| 成绩波动原因分析.md | 试卷难度、临场状态、样本量、口径统一 | 结合自身学习经验的总结整理 |
| 线性拟合与趋势预测.md | 最小二乘公式、R²、外推风险、无法拟合的情形 | 依据统计学基础教材内容（一元线性回归）整理 |
| 相关与因果的区别.md | 混淆变量、反向因果、因果证据强度 | 依据统计学/科学方法论的通用常识整理 |

## 说明

1. **资料为本项目自备**，范围刻意收窄在与"成绩分析"相关的主题上，便于演示"知识库内命中 / 知识库外拒答"的对比。
2. 检索索引在服务启动时自动构建（`app/tools/retrieval.py`），新增 `.md` 文件后重启服务即可被检索。
3. 片段切分规则：按空行分段、聚合到约 420 字符；文件名与小标题会参与索引，因此文件命名要能概括内容。
4. 回答时展示的"资料出处"就是这里的文件名 + 片段编号（如 `线性拟合与趋势预测.md#2`），可逐条核对原文。
